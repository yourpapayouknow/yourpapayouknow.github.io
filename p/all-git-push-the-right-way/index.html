本地项目上传github的坑点与正确姿势

100%不会遇到任何问题的正确上传方法

2026-03-16
阅读时长: 2 分钟

本地项目上传github的坑点与正确姿势

  • 首先，无论是什么IDE或者编辑器（VS、VScode、Pycharm、Idea、Clion等等），统统不要先在本地创建仓库。

一些坑点

  1. 要先绑定github远程仓库，可能出现各种奇怪的问题；
  2. git创建的本地仓库，分支名字是 master ，而github是 main ，直接上传会导致不同分支，不好看；
  3. 如果是使用IDE内的版本管理操作的，写完项目再创建仓库，添加文件是会出现困难，重新加 .gitignore 太麻烦了，还可能有各种报错；
  4. 仓库间文件不统一， 即使使用了 git pull 也还是会报各种错误；
  5. 可能因为各种权限问题导致被拒绝push。

建议的正确姿势

  1. 进入github主页，点击 New 创建同名的仓库；

    1

    https://github.com/
    • 点击左上角的绿色按钮，按照提示填即可。

  2. 创建完毕后，cd到项目存放地，使用 git clone 命令把仓库克隆过来；

    1

    git clone https://github.com/yourname/yourdepository
    • 请在预存放项目的地方打开终端，执行上面的link，后面的仓库地址可以直接从仓库页面下的浏览器链接栏里面复制。

  3. 将你要上传的所有文件全部复制进clone下来的文件夹里面；

    • 注意，超过100MB的文件无法上传github；
    • 注意使用AI添加一个 .gitignore 文件，把有的没的的路径都放进去。

  5. 后续的操作就转移到这个项目目录下进行即可，在IDE中图形化操作即可。

总结

请下次写项目前，先创建仓库别直接开写好吗 /smile
